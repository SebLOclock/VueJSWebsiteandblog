# Mon premier article en Markdown

Bienvenue sur le nouveau systeme de blog ! Les articles sont desormais rediges en **Markdown** et stockes directement dans le projet.

## Avantages

- Pas de backend a maintenir
- Deploiement par simple FTP
- Redaction rapide en Markdown
- Versionning avec Git

## Exemple de code

```javascript
const message = 'Hello World'
console.log(message)
```

## Conclusion

Ce systeme simplifie grandement la gestion du blog tout en gardant une experience de lecture agreable.
